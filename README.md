# SGEU: protótipo

Protótipo de média fidelidade do Sistema de Gestão de Eventos Universitários (Engenharia de Software I, Univali, 2026/2).

Página: https://mapompeo.github.io/sgeu-prototipo/

Telas: 1 eventos, 2A inscrição, 2B lista de espera, 3 presença, 4 inscrições e certificados, 5 cadastro externo, 6 emissão de certificados, 7 verificação de certificado, 8 cadastro/edição/cancelamento de evento, 9 análise de evento. Cada tela tem o seu endereço (`#t1`, `#t2a`, ...).
